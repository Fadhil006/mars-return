# Source register — A1 and A3

`ctx-dem.json` and `ctx-ortho.json` record downloaded, checksum-verified USGS/PDS CTX inputs. `science.json` records verified NASA/PDS regional-context sources; `science-candidates.json` retains unregistered named regions without invented sample coordinates. Records include URLs, mission/instrument, product IDs, temporal information where known, attribution and limitations. Null/unknown acquisition dates must not be replaced with publication dates. See `docs/data-method.md` and `docs/science-evidence.md`.
